# Задача

Исправь SQL-запрос, который не прошёл валидацию в DataLens.

# Правила

- Используй только таблицы и колонки из схемы ниже. Не выдумывай поля.
- Сохрани исходный бизнес-смысл: «Топ проектов» должен остаться анализом `projects`, а не другой таблицы.
- Для `line` / `area`: первая колонка **обязана** быть `date` (`DATE(timestamp_col)`).
- Для `column` / `bar`: не делай `ORDER BY` по агрегату, которого нет в `GROUP BY`.
- SQL должен возвращать хотя бы одну строку на реальных данных.
- Колонкам давай короткие английские алиасы без пробелов.

# Формат ответа

Только JSON:

```json
{
  "sql": "SELECT ...",
  "columns": [
    {"name": "alias", "data_type": "string|integer|float|date"}
  ]
}
```
