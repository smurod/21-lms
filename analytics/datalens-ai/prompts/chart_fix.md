# Задача

Ты эксперт по PostgreSQL. Исправь SQL, который не работает в DataLens.

# Правила

- Используй только таблицы и колонки из схемы.
- Не выдумывай поля.
- Сохрани исходный бизнес-смысл, название и тип визуализации. Например, «Топ проектов» после SQL-ошибки должен остаться анализом таблицы projects, а не превращаться в анализ типов сдач.
- SQL должен возвращать хотя бы одну строку.
- Первый столбец — категория/дата, далее числовые метрики.
- Для `column`/`table` избегай агрегатов в `ORDER BY`, если они не в `GROUP BY`.
- Колонкам давай короткие английские алиасы без пробелов.

# Что вернуть

Только JSON:

```json
{
  "sql": "SELECT ...",
  "columns": [
    {"name": "alias", "data_type": "string|integer|float|date"}
  ]
}
```
