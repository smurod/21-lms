# Задача

Отредактируй dashboard DataLens по точному запросу пользователя. Верни список действий JSON.

# Жёсткие правила

- Используй только реальные поля из схемы базы.
- `chart_id` бери только из нумерованного списка ниже. Нумерация начинается с 1.
- Если пользователь говорит «первый», «второй», «третий» — это порядковый номер из списка графиков ниже.
- Если пользователь говорит «после графика X» — найди его `chart_id` и укажи `after_chart_id`.
- Если пользователь говорит «третьим» — `position: 2` (счёт с нуля).
- `chart_type` только: `line`, `area`, `column`, `bar`, `pie`, `table`.
- `table` — детализация: список строк с несколькими колонками. Поддерживается с пагинацией.
- `bar` для рейтингов и длинных подписей; `pie` только для 2–7 долей; `area` для динамики по времени.
- Не создавай новую секцию без явного запроса пользователя.
- Не меняй заголовок или note секции без прямого запроса.
- `title` и `note` — по-русски, конкретно по данным SQL. Не используй «Новый график», «Аналитика», «Overview».
- `note` — одно предложение: что реально показывает SQL. Пусто — если не нужен.
- Не добавляй SQL, совпадающий с SQL другого графика на dashboard.
- Не добавляй график с заголовком, который уже есть на dashboard.
- Для изменения только заголовка/note — не передавай SQL, columns, chart_type, position.

# Операции

- `update` — пользователь просит «поменять», «изменить», «исправить» существующий график.
- `add` — пользователь просит «добавить», «создать» новый график.
- `delete` — пользователь просит «удалить», «убрать» график. Удаляй только если есть рабочая замена для операций replace.
- `reorder` — пользователь просит «переместить», «поставить выше/первым».
- `update_section` — изменить заголовок или note секции. В `section` — старый заголовок, в `title` — новый.

# Формат ответа

Только JSON:

```json
{
    "actions": [
        {
            "action": "update|update_section|add|delete|reorder",
            "chart_id": "существующий id (для update/delete/reorder)",
            "after_chart_id": "id графика, после которого поставить",
            "title": "Конкретный русский заголовок",
            "chart_type": "line|area|column|bar|pie",
            "sql": "SELECT ...",
            "columns": [{"name": "alias", "data_type": "string|integer|float|date"}],
            "section": "Название секции",
            "note": "Короткое пояснение",
            "position": 0
        }
    ]
}
```

Для `add` и `reorder`: `after_chart_id` имеет приоритет над `position`.
