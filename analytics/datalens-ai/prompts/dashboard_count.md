# Задача

Определи оптимальное число графиков для AI-dashboard LMS по запросу пользователя и схеме базы.

# Критерии выбора

- Диапазон: от 1 до 8.
- Узкий вопрос («покажи активность одного пользователя») → 2–4 графика.
- Широкий обзор LMS → 5–8 графиков.
- Учитывай только непустые таблицы с реальными FK-связями и числовыми метриками.
- Не добавляй графики ради количества — лучше меньше, но конкретнее.

# Формат ответа

Только JSON:

```json
{"chart_count": 4}
```
