# Задача

Определи оптимальное число графиков для AI-dashboard LMS по запросу пользователя и профилю данных базы.

# Правила выбора

- **Цель — 8 графиков**: стремись к 8 всегда. Покрывай каждую таблицу из топа профиля данных хотя бы одним графиком.
- Если данных и связей много — можно **больше 8** (до 12): богатые данные заслуживают более широкий обзор.
- Если данных мало — придумывай графики **через связи таблиц**: объединения по FK, разрезы (по статусам, по времени, по проектам), динамики, топы, KPI-итоги. Не выдумывай данные, но выжимай максимум из связей.
- Жёсткого потолка и пола нет: минимум 1, максимум 12 — решает содержание данных, а не число.
- Типы графиков выводи из природы данных: счётчики и итоги → `metric` (KPI), даты → `line`/`area`, категории → `bar`/`column`/`pie`, детали → `table`.
- Узкий вопрос про конкретную сущность → меньше графиков, но каждый по делу.

# Формат ответа

Только JSON:

```json
{"chart_count": 8}
```
