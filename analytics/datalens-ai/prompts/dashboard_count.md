# Задача

Ты планируешь объём AI dashboard для LMS. Определи, сколько действительно полезных и неповторяющихся визуализаций нужно создать по запросу пользователя.

# Правила

- Выбирай от 1 до 8 charts.
- Не стремись заполнить фиксированное число: краткий вопрос может требовать 1–3 charts, широкий обзор LMS — больше.
- Учитывай, какие непустые таблицы, реальные FK-связи и пригодные для визуализации поля доступны в схеме.
- Сокращай число charts, если у таблиц мало строк, нет связей или результат будет состоять из одной категории.
- Увеличивай число только если есть несколько независимых бизнес-вопросов с достаточно разными данными.
- Не добавляй charts ради количества.
- Для точечного пользователя или проекта обычно достаточно 2–5 charts.
- Верни только JSON без markdown.

```json
{"chart_count": 4}
```
