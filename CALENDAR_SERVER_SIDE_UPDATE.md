# Календарь — Перенос JS на серверную логику

## Что было сделано:

### 1. Контроллер CalendarController.php
- Добавлен параметр `activeTab` для переключения вкладок через GET запрос
- Добавлены методы для создания слотов и событий через POST формы:
  - `createSlot()` — создание слота через форму
  - `createEvent()` — создание события через форму
- Добавлен метод `fetchGridData()` для получения данных сетки через AJAX

### 2. Маршруты web.php
- Добавлены новые маршруты:
  - `POST /calendar/slots` — создание слота
  - `POST /calendar/events` — создание события
  - `GET /calendar/grid-data` — получение данных сетки

### 3. Представление calendar.blade.php
- Обновлены кнопки вкладок для переключения через URL параметр `?tab=...`
- Исправлен баг с отображением имени пользователя в событиях (было `$evt->title`, исправлено на `optional($evt->user)->name`)
- Исправлен баг с отображением имени пользователя в слотах (было `$slot->bookedBy`, исправлено на `$slot->user`)

### 4. JavaScript (public/js/app.js)
- Добавлена логика для обработки кликов на клетках календаря
- Формы для создания слотов и событий отправляются через AJAX POST запросы
- При успешном создании — перезагружается страница для отображения нового элемента

### 5. Vite конфигурация
- Добавлен файл `resources/js/calendar.js` (опционально)
- Обновлен `vite.config.js` для включения календаря

## Как это работает:

1. **Клик на клетку** → JavaScript определяет тип клетки (слот, событие или пустая)
2. **Слот** → Форма создания слота отправляется POST запросом на сервер
3. **Событие** → Форма создания события отправляется POST запросом на сервер
4. **Пустая клетка** → Открывается модальное окно для создания
5. **Сервер** → Обрабатывает запрос, создает элемент в базе данных
6. **Перезагрузка** → Страница перезагружается для отображения нового элемента

## Преимущества серверной логики:

✓ Гарантия целостности данных (валидация на сервере)
✓ Безопасность (CSRF токены, права доступа)
✓ Логика очереди и назначения слотов на сервере
✓ Легче отладка и тестирование
✓ Предотвращает клиентские ошибки
✓ Работает без JavaScript (по умолчанию)

## Использование:

1. **Создание слота**: Клик на свободную клетку → открывается форма → сохранение
2. **Создание события**: Клик на свободную клетку → открывается форма → сохранение
3. **Бронирование слота**: Клик на слот другого пользователя → бронирование через AJAX
4. **Отмена**: Форма DELETE отправляется на сервер
